Calibrate PM Agent Team output to reality: this is an internal tool plus trainee onboarding tool, not a market product. TAM/SAM/SOM and 5-competitor analysis should be brief and honest — one paragraph saying whether sizing is decision-relevant beats padded numbers. Competitors (Gamma, Beautiful.ai, Canva, Tome, Copilot) are compared on where they fail a professional producer, not on feature checklists.

**Why:** The requester explicitly asked for this on 2026-09-04 — effort belongs on the three real user segments and on observed failure evidence, and fabricated evidence is forbidden ("use this, do not invent").

**How to apply:** Any future `/pdca pm` run in this repo: keep research sections short, root the OST in the 대표's named axes, label inferences `추정:`, and end the PRD with a ranked problem list (what breaks / where it lives / what changes / rough size). No emojis in deliverables.

Operational note (2026-09-04): background sub-agent results land on later turns, not in the turn that spawned them. Have each sub-agent write to a scratchpad file, check the scratchpad before synthesising, write the PRD with whatever is on disk (marking provenance per section), and merge late arrivals with targeted edits rather than blocking.
